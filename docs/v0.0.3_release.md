# v0.0.3 发布说明

**发布日期：** 2026-07-05

## 核心功能：Cartographer SLAM 建图

本版本实现了在 Gazebo 仿真环境中使用 Google Cartographer 算法进行 2D SLAM 建图的完整工作流。

### 功能概述

- **Cartographer 2D SLAM**：集成 `ros-jazzy-cartographer-ros` 二进制包，支持激光扫描匹配建图
- **一体化启动**：`slam_sim.launch.py` 一键启动 Gazebo 仿真 + Cartographer SLAM + rviz2 可视化
- **键盘控制建图**：使用 `teleop_twist_keyboard` 控制机器人在迷宫中移动建图
- **地图保存**：通过 Cartographer 服务保存 pbstream 格式地图文件

### 使用方法

```bash
# 1. 构建镜像
bash scripts/docker_run.sh --no-cache --gui --mirror ustc

# 2. 容器内启动仿真 + SLAM
source /ros2_ws/install/setup.bash
ros2 launch Prodev_slam slam_sim.launch.py

# 3. 新终端，键盘控制建图
docker exec -it prodev_jazzy_container bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard

# 4. 保存地图
ros2 service call /finish_trajectory cartographer_ros_msgs/srv/FinishTrajectory "{trajectory_id: 0}"
ros2 service call /write_state cartographer_ros_msgs/srv/WriteState "{filename: '/ros2_ws/map.pbstream'}"
```

### 技术细节

- **传感器**：360° LiDAR（10Hz）+ IMU（100Hz）+ 差速驱动里程计（100Hz）
- **TF 链路**：`map → odom → base_link → laser_link`
- **Cartographer 配置**：`cartographer_2d.lua`，启用在线扫描匹配和 IMU 数据融合
- **DiffDrive 插件**：配置 `odom_frame_id` 和 `child_frame_id` 消除 Gazebo 模型名前缀

### 已知问题

- rviz2 中 EGL 渲染警告（不影响功能，与 GPU 驱动相关）
- Cartographer 启动时可能有短暂的 TF 等待日志（正常现象）
